Lookup catalogues of shared utilities. Code is truth — these pages point you at the right file and flag what's deprecated; they don't restate signatures the type system already gives you.

| Reference | What it covers |
|---|---|
| [Utilities](100-Utilities.md) | Small, focused helpers under `$lib/utils/` and the deprecated migration helpers. |
